# Path tree sorter

Скрипт, который компонирует все файлы из определённой папки в виде дерева по определённым критериям

## For usage

Чтобы попробовать скрипт с примером использования: 

```sh
python -m venv .venv
.venv/Scripts/activate
python main.py
```

> ❗ [Установите Python](https://www.python.org/downloads/?hl=RU) перед использованием
